These files contain the implementation of an isolated LAN communication system I developed to securely connect five different locations, enabling reliable file and data sharing across the network.

The system includes separate user roles (Users, Administrators, and Safety Users), each with dedicated permissions and capabilities to control access and maintain network security.

It also incorporates safety mechanisms designed to ensure reliable operation, prevent unauthorized access, and detect or handle potential network issues and system faults.
